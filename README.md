# AnalystLab Africa: Data Science Internship Project

## Overview

This repository documents my 8-week Data Science Internship with AnalystLab Africa. The program takes a learner from raw data all the way to a deployed, working machine learning application, covering data cleaning, statistics, supervised learning, feature engineering, model optimization, deployment, and a final capstone project.

The datasets used throughout are the **Titanic Dataset** and the **House Prices Dataset**, with the final capstone project using the **World Bank World Development Indicators (WDI)** dataset.

## Project Goal

To apply the complete data science workflow: cleaning, exploring, modeling, optimizing, and deploying to real-world data, and to build a professional portfolio that demonstrates these skills to employers.

---

## Week-by-Week Breakdown

### Week 1–2: Data Cleaning and Exploratory Data Analysis (EDA)
Load, inspect, and clean the Titanic and House Prices datasets. Handle missing values and duplicates, correct data types, and perform univariate and bivariate analysis. Generate a correlation heatmap and produce at least 5 key insights per dataset.
**Deliverables:** Cleaned CSVs, Jupyter Notebook, Insight Summary Report.

### Week 3: Statistics and Probability
Apply descriptive statistics, probability distributions, and hypothesis testing to the cleaned datasets from Week 1–2. Explore the difference between correlation and causation.
**Deliverables:** Notebook with statistical analysis, summary report.

### Week 4: Supervised Learning
Build a Linear Regression model to predict house prices and a Logistic Regression model to predict Titanic passenger survival. Split data into training/testing sets and evaluate performance using RMSE and Accuracy.
**Deliverables:** ML notebook, model evaluation report.

### Week 5: Advanced Machine Learning
Build and compare a baseline model, Decision Tree, Random Forest, and Gradient Boosting models on the House Prices dataset. Apply hyperparameter tuning (GridSearchCV/RandomizedSearchCV) and compare performance before and after tuning.
**Deliverables:** Notebook, performance comparison report, GitHub repo.

### Week 6: Feature Engineering and Model Optimization
Create new features from raw variables, apply transformations (scaling, encoding), and select the most relevant features using correlation analysis or feature importance. Optimize the model using cross-validation and hyperparameter tuning.
**Deliverables:** Notebook, optimized model, performance comparison report.

### Week 7: Model Deployment and Real-World Application
Save the trained model using pickle or joblib, build a prediction API with Flask or FastAPI, and test it. Optionally build a simple Streamlit interface for users to interact with the model.
**Deliverables:** Saved model file, working API/app, README, demo video.

### Week 8: Data Science Capstone Project
Apply the full data science workflow end-to-end using the World Bank World Development Indicators (WDI) dataset. Define a real-world problem, clean and explore the data, build and evaluate at least two machine learning models, and present actionable insights.
**Deliverables:** Full project notebook, report, GitHub repository.
